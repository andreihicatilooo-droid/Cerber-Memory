# Инструкция по запуску CERBER Memory через Docker

Этот проект поддерживает быстрый запуск в полностью изолированных Docker-контейнерах (сервис памяти `cerber` + векторная СУБД `qdrant`).

---

## Быстрый старт (одной командой)

Перейдите в директорию проекта и запустите интерактивный скрипт установки:

```bash
cd cerber-memory
./run.sh
```

Скрипт автоматически:
1. Проверит наличие Docker и Docker Compose.
2. Создаст файл конфигурации `.env` (если его нет).
3. Спросит у вас **Gemini API Key** и сохранит его.
4. Сгенерирует безопасный уникальный 32-значный ключ шифрования для AES-256 (`CERBER_MASTER_KEY`).
5. Соберет и запустит контейнеры в фоновом режиме.

После успешного завершения:
* **Веб-интерфейс (дашборд):** [http://localhost:8080](http://localhost:8080)
* **Панель Qdrant:** [http://localhost:6333/dashboard](http://localhost:6333/dashboard)

---

## Ручной запуск

Если вы хотите запустить контейнеры вручную без интерактивного скрипта:

1. Скопируйте шаблон окружения:
   ```bash
   cp .env-dist .env
   ```
2. Откройте `.env` и укажите ваш ключ:
   ```env
   GEMINI_API_KEY=ваш_ключ_от_gemini_api
   CERBER_MASTER_KEY=укажите_32_символьный_ключ_шифрования
   ```
3. Запустите сервисы:
   ```bash
   docker-compose up --build -d
   ```

---

## Полезные команды

* **Остановить контейнеры:**
  ```bash
  docker-compose down
  ```
* **Просмотр логов:**
  ```bash
  docker-compose logs -f
  ```
* **Логи конкретно приложения `cerber`:**
  ```bash
  docker-compose logs -f cerber
  ```
* **Перезапустить только веб-сервер (без Qdrant):**
  ```bash
  docker-compose restart cerber
  ```
* **Очистить базу данных и сбросить хранилище:**
  Удалите локально созданную папку `data`:
  ```bash
  docker-compose down
  rm -rf ./data
  ```
