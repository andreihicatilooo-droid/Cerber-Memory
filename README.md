# CERBER Memory MVP

CERBER Memory — это гибридный конвейер (Пайплайн + MVC) для управления памятью агента.
Он принимает сырой неструктурированный текст (например, от первичного агента), анализирует его с помощью LLM (Gemini API) и автоматически распределяет извлеченную информацию по различным категориям памяти (база данных SQLite).

## Категории памяти:
- **Core Memory** — важные системные факты и контекст.
- **Notes** — полезные заметки, логи, ссылки.
- **Ideas** — мысли и возможные улучшения.
- **Goals** — высокоуровневые цели.
- **Tasks** — конкретные шаги.

## Требования:
- Go 1.22+
- Переменная окружения `GEMINI_API_KEY` (с валидным ключом от Google Gemini API)

## Установка и запуск:
```bash
cd cerber-memory
go build -o cerber ./cmd/cerber

# Установите ваш API ключ
export GEMINI_API_KEY="your_api_key_here"

# Запуск приложения (ожидает текст через Stdin)
echo "Сегодня я понял, что нам нужно перейти на PostgreSQL для лучшей масштабируемости (это идея). Также не забудь обновить документацию (задача) и цель - завершить MVP к пятнице." | ./cerber
```
